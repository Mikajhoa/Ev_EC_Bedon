## Descripción
Sala de entrenamiento XR en Unity con objetos manipulables e interacción a distancia mediante rayo.

## Funcionalidades implementadas
- Configuración del proyecto con URP y XR Interaction Toolkit
- Escena EC_XR_ApellidoNombre con piso, iluminación, límites y 5 objetos 3D
- Objetos manipulables con Rigidbody y XR Grab Interactable
- Interacción a distancia: encender/apagar luz con rayo
- Reto libre: teletransporte

## Controles
- **Grip:** agarrar objetos
- **Rayo + Trigger:** activar el botón de la luz
- **Joystick:** teletransporte
- (Con simulador: usar los controles del XR Device Simulator)
